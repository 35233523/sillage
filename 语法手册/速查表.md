# SILLAGE（航迹）· 速查表

> 一张纸看完 SILLAGE v1.0。详细讲解见 `语法手册.md`。

---

## 1. 语法骨架

```sillage
que x vaille 42                 ‖ 绑定新名字（也可写 soit x vaille 42 / donne 42 à x）
que x devienne x plus 1         ‖ 重绑定（必须已存在）
affiche x                       ‖ 打印（dis / trace 等价）
rends x                         ‖ 返回；顶层 rends 结束整个模块
silence                         ‖ 空句；作为最后一条顶层句时把模块结果压成 VIDE
```

## 2. 语句

| 语义 | 写法 |
|---|---|
| 条件 | `si C alors ⟦ … ⟧ sinonsi C2 alors ⟦ … ⟧ sinon ⟦ … ⟧` |
| 当型循环 | `tant que C ⟦ … ⟧`（或 `tantque` / `boucle`） |
| 遍历 | `pour chaque v dans xs ⟦ … ⟧` |
| 跳出 / 下一轮 | `arrête`（`casse`）/ `continue`（`passe`） |
| 定义函数 | `on définit f de a et b comme ⟦ … ⟧`（或 `de (a, b)`） |

> `⟦` 必须和引导词（`alors` / `comme` / 循环条件）在**同一行**。

## 3. 值

| 类型 | 字面量 | 说明 |
|---|---|---|
| 数字 | `42` `3.5` `0 moins 7` | 只有一种数字，定点 9 位小数，上限 1e15，无科学计数法 |
| 文本 | `"有转义"` `«不转义»` | 按字素计长，下标 1 起 |
| 序列 | `‹1, 2, 3›` `‹›` | 不可变，可混装 |
| 记录 | `⟬a ⟼ 1, b ⟼ 2⟭` `⟬⟭` | 键为文本，保持插入序 |
| 真 / 假 | `OUI` `vrai` / `NON` `faux` | |
| 空 | `VIDE` `vide` `rien` | |

真值：假 = `NON` `0` `""` `‹›` `⟬⟭` `VIDE`；其余（含 `"0"`）都真。

## 4. 运算符（词与符号等价）

| 语义 | 词 | 符号 |
|---|---|---|
| 加 / 拼接 | `plus` | `+` `⊕` |
| 减 | `moins` | `-` `−` `⊖` |
| 乘 | `fois` | `*` `×` `⊗` |
| 除 | `sur` | `/` `÷` `⊘` |
| 取模 | `modulo` | `%` `⊞` |
| 幂（右结合） | `puissance` | `^` `↑` |
| 相等 | `égal à` / `égal` | `=` `==` `≟` |
| 不等 | `différent de` | `≠` `≢` |
| > < | `plus grand que` / `plus petit que` | `>` `<` |
| ≥ ≤ | `au moins` / `au plus` | `>=` `<=` |
| 且 / 或 / 非 | `et` / `ou` / `non` | `&&` `\|\|` / `!` `¬` |

优先级：`élément`/`champ` → 一元 → `puissance` → `fois sur modulo` → `plus moins` → 比较 → `et` → `ou`。

**没有 `!=`。**

## 5. 内置函数 18 个

```
mesure      en-texte   en-nombre   égalise   abaissé   haussé
découpe     recoud     renferme    clefs     teneurs   ajoute-fin
bribe       ordonne    total       tordu     fige      absolu
```

调用一律介词式：

```sillage
mesure de xs
découpe de t par ","
recoud de xs avec "-"
renferme de f dans "k"       ‖ 第一个是容器，第二个是被查项
tordu de f avec "k" et v
bribe de xs depuis 2 jusqu'à 4
```

## 7. 模块结果（三条规则 + 特例）

1. 第一条真正执行的**顶层** `rends` → 它的值，模块立即结束；
2. 否则：最后一条**顶层表达式句**的值；
3. 否则 `VIDE`；
4. 特例：最后一条顶层句是 `silence` → 强制 `VIDE`。

## 8. 错误

```json
{"défaut": {"étape": "calcul", "ligne": null, "note": "indice hors limites"}}
```

`étape` 只有六种：`lexique` `syntaxe` `forme` `nom` `calcul` `hôte`。

## 9. 命令行

```
sillage_c.exe                     交互式 REPL（双击等价）
sillage_c.exe repl                同上
sillage_c.exe test                内置自测
sillage_c.exe run <文件> [JSON]   跑模块
sillage_c.exe call <文件> <函数> [JSON]   调函数
sillage_c.exe ast <文件>          语法树
sillage_c.exe --server [--store <JSON>]   RPC
```

REPL 命令：`:help` `:reset` `:load <文件>` `:quit`。

## 10. 十个坑

1. `⟦` 与引导词必须同一行；
2. `mesure de xs plus 1` 被当成 `mesure(xs + 1)`，要写 `(mesure de xs) plus 1`；
3. `x-1` 是一个名字，减法写 `x moins 1`；
4. `1e3` 不是 1000；
5. `ajoute-fin` 返回新序列，原序列不变，要 `que xs devienne …`；
6. `ajoute-fin de xs avec ‹1,2›` 只追加了一个元素；
7. `champ` 缺键直接报错，先 `renferme de f dans k`；
8. `arrête` / `continue` 只能在循环体里；
9. C 引擎不支持零参调用 `f de ()`，用占位参数 `f de 0`；
10. `atelier.lancer` 的路径按「项目根」解析，CLI 里加 `--store 数据\sillage.json`。
