# SILLAGE · 别名表（同一条语义的全部等价拼写）

> 一门语言里同一个意思可以有几种写法，是 SILLAGE 的教学设计：
> 先认全，再用熟。本表由 `示例程序/程序/zoo.sil` 与引擎实现共同核对。

## 1. 语句

| 语义 | 全部拼写 |
|---|---|
| 绑定新名字 | `que x vaille e` · `soit x vaille e` · `donne e à x` |
| 重绑定 | `que x devienne e` · `soit x devienne e` · `que x remue e` · `soit x remue e` |
| 打印 | `affiche e` · `dis e` · `trace e` |
| 返回 | `rends e` |
| 空句 | `silence` |
| 条件引导 | `si` · `quand` · `lorsque` |
| 否则如果 | `sinonsi` · `oualors` |
| 否则 | `sinon` · `autrement` |
| 当型循环 | `tant que` · `tantque` · `boucle` |
| 遍历 | `pour chaque` |
| 跳出 | `arrête` · `casse` |
| 下一轮 | `continue` · `passe` |
| 定义函数 | `on définit … de … comme` |

## 2. 真值字面量

| 语义 | 拼写 |
|---|---|
| 真 | `OUI` · `vrai` · `☑` |
| 假 | `NON` · `faux` · `☒` |
| 空 | `VIDE` · `vide` · `rien` · `∅` |

## 3. 运算符

| 语义 | 词 | 符号 |
|---|---|---|
| 加 | `plus` | `+` `⊕` |
| 减 | `moins` | `-` `−` `⊖` |
| 乘 | `fois` | `*` `×` `⊗` |
| 除 | `sur` | `/` `÷` `⊘` |
| 取模 | `modulo` | `%` `⊞` |
| 幂 | `puissance` | `^` `↑` |
| 相等 | `égal à` · `égal` | `=` `==` `≟` |
| 不等 | `différent de` · `différent` | `≠` `≢` |
| 大于 | `plus grand que` | `>` `⪢` |
| 小于 | `plus petit que` | `<` `⪡` |
| 大于等于 | `au moins` | `>=` `≥` `⩾` |
| 小于等于 | `au plus` | `<=` `≤` `⩽` |
| 且 | `et` | `&&` `∧` |
| 或 | `ou` | `\|\|` `∨` |
| 非 | `non` | `!` `¬` |

## 4. 文本字面量

| 写法 | 例 | 转义 |
|---|---|---|
| 双引号 | `"a\nb"` | 有（`\n` `\t` `\r` `\"` `\\`） |
| 尖引号 | `«C:\path»` | 无，原样保留 |

## 5. 容器字面量

| 语义 | 写法 |
|---|---|
| 空序列 | `‹›` |
| 序列 | `‹1, 2, 3›` |
| 空记录 | `⟬⟭` |
| 记录 | `⟬a ⟼ 1, b ⟼ 2⟭` |

## 6. 注释

| 写法 | 例 |
|---|---|
| 竖线 | `‖ 注释` |
| 井号 | `# 注释` |

两者都到行尾；字符串里的 `‖`、`#` 不是注释。

## 7. 块括号

| 规范 | 键盘替代（仅 REPL） |
|---|---|
| `⟦ … ⟧` | `{ … }` |

文件里必须写 `⟦ … ⟧`（实测 `{` 在文件里报语法错）。

## 8. 调用

| 语义 | 写法 |
|---|---|
| 一元 | `f de x` |
| 二元（第二参 `par`） | `f de x par sep` |
| 二元（第二参 `avec`） | `f de xs avec sep` |
| 二元（第二参 `dans`） | `f de 容器 dans 被查项` |
| 三元 | `f de f avec k et v` |
| 区间 | `f de x depuis a jusqu'à b` |
| 用户函数多参 | `f de a et b` |
| 括号写法（可用但不推荐） | `f(a, b)` |
| 宿主服务 | `carnet.lister "posts"`（点分名 + 并置） |

## 9. 索引与字段

| 语义 | 写法 |
|---|---|
| 序列/文本下标（1 起） | `élément i de xs` |
| 记录取字段 | `champ "键" de f` |
